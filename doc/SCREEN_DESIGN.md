## 2. 共通仕様

### 2-1. ナビゲーション

全画面共通のサイドバーまたはヘッダーナビゲーションを表示する。

| 項目       | リンク先     | 表示ロール |
| ---------- | ------------ | ---------- |
| 日報一覧   | `/reports`   | 全ロール   |
| 顧客マスタ | `/customers` | 全ロール   |
| 営業マスタ | `/users`     | 管理者のみ |
| ログアウト | —            | 全ロール   |

### 2-2. 共通エラー表示

- バリデーションエラーはフォーム各項目の直下に赤字で表示する
- API通信エラーはページ上部にトースト通知で表示する
- 権限エラーは 403 ページへリダイレクトする

### 2-3. 日付・時刻フォーマット

| 種別 | フォーマット     | 例               |
| ---- | ---------------- | ---------------- |
| 日付 | YYYY/MM/DD       | 2026/05/13       |
| 時刻 | HH:mm            | 14:30            |
| 日時 | YYYY/MM/DD HH:mm | 2026/05/13 14:30 |

## 3. ログイン画面 `SCR-001`

### 概要

メールアドレスとパスワードで認証し、日報一覧画面へ遷移する。

### レイアウト

```
┌─────────────────────────────┐
│        営業日報システム       │
│                             │
│  メールアドレス               │
│  [___________________________]│
│                             │
│  パスワード                   │
│  [___________________________]│
│                             │
│  [    ログイン    ]           │
└─────────────────────────────┘
```

### 項目定義

| 項目名         | 種別       | 必須 | バリデーション |
| -------------- | ---------- | ---- | -------------- |
| メールアドレス | テキスト   | ○    | メール形式     |
| パスワード     | パスワード | ○    | 1文字以上      |

### アクション

| アクション         | 処理                                                                   |
| ------------------ | ---------------------------------------------------------------------- |
| ログインボタン押下 | 認証API呼び出し → 成功時 `/reports` へ遷移、失敗時エラーメッセージ表示 |

## 4. 日報一覧画面 `SCR-002`

### 概要

日報の一覧を表示する。営業は自分の日報のみ、マネージャー・管理者はチーム全体を閲覧できる。

### レイアウト

```
┌────────────────────────────────────────────────────┐
│ 日報一覧                          [+ 新規作成]       │
│                                                    │
│ 絞り込み: [担当者 ▼] [ステータス ▼] [期間: 〜 ]  [検索]│
│                                                    │
│ ┌──────┬──────────┬────────┬────────┬────────────┐ │
│ │ 日付 │  担当者  │ 訪問先 │ステータス│  提出日時  │ │
│ ├──────┼──────────┼────────┼────────┼────────────┤ │
│ │05/13 │ 山田 太郎│ 株式会社A 他2件│提出済み│05/13 18:00│ │
│ │05/12 │ 山田 太郎│ 株式会社B     │下書き  │—          │ │
│ └──────┴──────────┴────────┴────────┴────────────┘ │
│                           [< 前へ]  1/5  [次へ >] │
└────────────────────────────────────────────────────┘
```

### 絞り込み条件

| 条件         | 種別                                         | 初期値                                 | 表示ロール               |
| ------------ | -------------------------------------------- | -------------------------------------- | ------------------------ |
| 担当者       | セレクトボックス（users一覧）                | 全員（マネージャー）/ 本人固定（営業） | マネージャー・管理者のみ |
| ステータス   | セレクトボックス（全件 / 下書き / 提出済み） | 全件                                   | 全ロール                 |
| 期間（開始） | 日付ピッカー                                 | 当月1日                                | 全ロール                 |
| 期間（終了） | 日付ピッカー                                 | 今日                                   | 全ロール                 |

### 一覧項目

| 列名       | データソース                     | 備考                         |
| ---------- | -------------------------------- | ---------------------------- |
| 日付       | `daily_reports.report_date`      | 降順ソート（固定）           |
| 担当者     | `users.name`                     | マネージャー・管理者のみ表示 |
| 訪問先     | `visit_records → customers.name` | 最初の1件 + 「他N件」形式    |
| ステータス | `daily_reports.status`           | 下書き / 提出済み バッジ表示 |
| 提出日時   | `daily_reports.submitted_at`     | 下書きは「—」                |

### アクション

| アクション     | 処理                       |
| -------------- | -------------------------- |
| 新規作成ボタン | `/reports/new` へ遷移      |
| 行クリック     | `/reports/:id` へ遷移      |
| 検索ボタン     | 絞り込み条件でリスト再取得 |

## 5. 日報作成・編集画面 `SCR-003`

### 概要

日報を新規作成または編集する。訪問記録は複数件追加できる。提出後は当日中のみ編集可能。

### レイアウト

```
┌──────────────────────────────────────────────────────┐
│ 日報作成                                              │
│                                                      │
│ 日付 [2026/05/13]                                    │
│                                                      │
│ ── 訪問記録 ──────────────────────────────────────── │
│ [+ 訪問先を追加]                                      │
│                                                      │
│ ┌────────────────────────────────────────────────┐   │
│ │ #1  顧客 [株式会社A        ▼]  訪問時刻 [14:00]│   │
│ │     訪問内容                                   │   │
│ │     [________________________________]         │   │
│ │     [________________________________]    [削除]│   │
│ └────────────────────────────────────────────────┘   │
│ ┌────────────────────────────────────────────────┐   │
│ │ #2  顧客 [株式会社B        ▼]  訪問時刻 [16:30]│   │
│ │     訪問内容                                   │   │
│ │     [________________________________]         │   │
│ │     [________________________________]    [削除]│   │
│ └────────────────────────────────────────────────┘   │
│                                                      │
│ ── 課題・相談（Problem）──────────────────────────── │
│ [__________________________________________________]  │
│ [__________________________________________________]  │
│                                                      │
│ ── 明日やること（Plan）───────────────────────────── │
│ [__________________________________________________]  │
│ [__________________________________________________]  │
│                                                      │
│           [下書き保存]         [提出する]             │
└──────────────────────────────────────────────────────┘
```

### 項目定義

#### 日報ヘッダー

| 項目名 | 種別         | 必須 | バリデーション           | 備考                           |
| ------ | ------------ | ---- | ------------------------ | ------------------------------ |
| 日付   | 日付ピッカー | ○    | 未来日付は不可・重複不可 | 新規作成時は今日の日付で初期化 |

#### 訪問記録（1件ごと）

| 項目名   | 種別                              | 必須 | バリデーション         | 備考                       |
| -------- | --------------------------------- | ---- | ---------------------- | -------------------------- |
| 顧客     | セレクトボックス（customers一覧） | ○    | —                      | インクリメンタルサーチ対応 |
| 訪問時刻 | 時刻ピッカー                      | —    | HH:mm形式              | 任意入力                   |
| 訪問内容 | テキストエリア                    | ○    | 1文字以上 2000文字以下 | —                          |

- 訪問記録は1件以上必須
- 最大件数は10件まで（要件確認）
- 追加ボタンで末尾に空欄の訪問記録ブロックを追加
- 削除ボタンで該当ブロックを除去（1件のみの場合は削除不可）

#### Problem / Plan

| 項目名                | 種別           | 必須 | バリデーション |
| --------------------- | -------------- | ---- | -------------- |
| 課題・相談（Problem） | テキストエリア | —    | 2000文字以下   |
| 明日やること（Plan）  | テキストエリア | —    | 2000文字以下   |

### アクション

| アクション             | 処理                                                                                 |
| ---------------------- | ------------------------------------------------------------------------------------ |
| 下書き保存             | `status=draft` で保存 → 一覧画面へ遷移                                               |
| 提出する               | バリデーション後 `status=submitted`・`submitted_at=現在時刻` で保存 → 詳細画面へ遷移 |
| 削除ボタン（訪問記録） | 該当訪問記録ブロックをフォームから除去                                               |
| 訪問先を追加           | 末尾に空の訪問記録ブロックを追加                                                     |

### アクセス制御

- 本人以外は編集画面にアクセス不可（403）
- 提出済みかつ翌日以降は編集不可（403）

## 6. 日報詳細画面 `SCR-004`

### 概要

日報の内容を閲覧し、マネージャーが Problem・Plan にコメントを投稿できる。

### レイアウト

```
┌──────────────────────────────────────────────────────┐
│ 日報詳細  2026/05/13  山田 太郎  [提出済み]  [編集]   │
│                                                      │
│ ── 訪問記録 ──────────────────────────────────────── │
│ ┌────────────────────────────────────────────────┐   │
│ │ 14:00  株式会社A                               │   │
│ │ 新製品のデモを実施。担当者の反応は良好。        │   │
│ └────────────────────────────────────────────────┘   │
│ ┌────────────────────────────────────────────────┐   │
│ │ 16:30  株式会社B                               │   │
│ │ 競合他社との比較表を要求された。来週までに準備。│   │
│ └────────────────────────────────────────────────┘   │
│                                                      │
│ ── 課題・相談（Problem）──────────────────────────── │
│ 株式会社Bへの提案資料について上長に相談したい。       │
│                                                      │
│ ▼ コメント                                           │
│ ┌────────────────────────────────────────────────┐   │
│ │ 鈴木 部長  05/13 19:00                         │   │
│ │ 先週の提案書をベースに修正してみて。            │   │
│ └────────────────────────────────────────────────┘   │
│ [コメントを入力...                    ] [投稿]        │
│                                                      │
│ ── 明日やること（Plan）───────────────────────────── │
│ 株式会社B向け比較表の作成。                          │
│                                                      │
│ ▼ コメント                                           │
│ （コメントなし）                                     │
│ [コメントを入力...                    ] [投稿]        │
└──────────────────────────────────────────────────────┘
```

### 表示項目

| 項目         | データソース                  | 備考                         |
| ------------ | ----------------------------- | ---------------------------- |
| 日付         | `daily_reports.report_date`   | —                            |
| 担当者名     | `users.name`                  | —                            |
| ステータス   | `daily_reports.status`        | バッジ表示                   |
| 訪問記録一覧 | `visit_records` + `customers` | 訪問時刻昇順                 |
| Problem      | `daily_reports.problem`       | 空の場合「（なし）」表示     |
| Plan         | `daily_reports.plan`          | 空の場合「（なし）」表示     |
| コメント一覧 | `comments`                    | target別に表示、投稿日時昇順 |

### アクション

| アクション              | 処理                            | 利用可能ロール         |
| ----------------------- | ------------------------------- | ---------------------- |
| 編集ボタン              | `/reports/:id/edit` へ遷移      | 本人かつ編集可能期間内 |
| コメント投稿（Problem） | `target=problem` でコメント保存 | マネージャー・管理者   |
| コメント投稿（Plan）    | `target=plan` でコメント保存    | マネージャー・管理者   |

### コメント項目定義

| 項目名       | 種別           | 必須 | バリデーション         |
| ------------ | -------------- | ---- | ---------------------- |
| コメント本文 | テキストエリア | ○    | 1文字以上 1000文字以下 |

## 8. 顧客マスタ作成・編集画面 `SCR-006`

### 概要

顧客情報を登録・編集する。

### 項目定義

| 項目名         | 種別           | 必須 | バリデーション     |
| -------------- | -------------- | ---- | ------------------ |
| 会社名         | テキスト       | ○    | 100文字以下        |
| 担当者名       | テキスト       | ○    | 50文字以下         |
| 部署           | テキスト       | —    | 100文字以下        |
| メールアドレス | テキスト       | —    | メール形式         |
| 電話番号       | テキスト       | —    | 数字・ハイフンのみ |
| 住所           | テキスト       | —    | 200文字以下        |
| 備考           | テキストエリア | —    | 1000文字以下       |

### アクション

| アクション               | 処理                                   |
| ------------------------ | -------------------------------------- |
| 保存ボタン               | バリデーション後 保存 → 顧客一覧へ遷移 |
| キャンセル               | 顧客一覧へ遷移                         |
| 削除ボタン（編集時のみ） | 確認ダイアログ → 削除 → 顧客一覧へ遷移 |

> 顧客削除は論理削除（`deleted_at` カラム）とし、過去の `visit_records` データを保持する。論理削除済みの顧客は一覧・セレクトボックスに表示しない。

## 10. 営業マスタ作成・編集画面 `SCR-008`

### 概要

ユーザー情報を登録・編集する。

### 項目定義

| 項目名         | 種別                                             | 必須                | バリデーション   |
| -------------- | ------------------------------------------------ | ------------------- | ---------------- |
| 氏名           | テキスト                                         | ○                   | 50文字以下       |
| メールアドレス | テキスト                                         | ○                   | メール形式・一意 |
| パスワード     | パスワード                                       | ○（新規）/—（編集） | 8文字以上        |
| ロール         | セレクトボックス（営業 / マネージャー / 管理者） | ○                   | —                |
| チーム         | セレクトボックス（teams一覧）                    | —                   | —                |

### アクション

| アクション               | 処理                                         |
| ------------------------ | -------------------------------------------- |
| 保存ボタン               | バリデーション後 保存 → 営業マスタ一覧へ遷移 |
| キャンセル               | 営業マスタ一覧へ遷移                         |
| 削除ボタン（編集時のみ） | 確認ダイアログ → 論理削除 → 一覧へ遷移       |

> ユーザー削除は論理削除（`deleted_at` カラム追加を推奨）とし、過去の日報データを保持する。
